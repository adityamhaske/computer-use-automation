Banks run a long tail of back-office applications with no API. When an AI agent needs to get real work done, the only way in is to drive the UI the way a human operator would. Doing that with an LLM on every invocation is slow, expensive, non-deterministic, and unauditable — three of which are disqualifying in a regulated environment.

What makes this architecture different

Every claim below is mechanically enforced by automated invariant tests that fail if broken.

Deterministic Replay

Same artifact + same inputs + same app state = identical decision trace. No model in the loop, zero temperature, no network calls to LLMs.

Semantic Targeting

Controls are identified by role, accessible name, and structural anchors — never brittle CSS selectors. A six-rung ladder survives markup churn.

Policy Chokepoint

Every action — from LLM discovery, replay engine, or human operator — passes through one authorization chokepoint. Zero bypasses, zero exceptions.

Fail Closed

Unknown UI states stop the run immediately. Ambiguous targets are refused, never guessed. In banking, an unverified click is an incident.

Human Escalation Lease

An operator takes the live session, acts under policy, and hands it back. The engine re-anchors and resumes at the right step, not step 1.

Multi-Tenant Overlays

A rebranded tenant label requires a four-line overlay document, not a re-record. Drift is quantified per tenant before replays fail.

The execution pipeline

One path to a surface, for every actor. No action reaches a driver without authorization.

Action
click, type, navigate
→
TargetResolver
resolve or refuse
→
PolicyEngine
authorize
→
SurfaceDriver
dispatch
  • Replay never calls or imports the LLM
  • No action reaches a driver without policy authorization
  • Target identity is semantic, never a CSS selector
  • Human input cannot bypass policy or evidence
  • Unknown UI states fail closed
  • Every sink is redacted — logs, artifacts, LLM prompts
  • Business outcomes are not failures
  • Automation may only act while it holds the session lease
  • Capabilities are immutable and content-hashed
  • The domain layer is pure — no I/O, no network, no browser

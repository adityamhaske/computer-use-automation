Computer-use automation for regulated back-offices

Discovery is probabilistic.
Execution is deterministic.

An LLM works out how to accomplish a goal in an enterprise legacy application — once. That discovery is compiled into a typed, versioned capability artifact. From then on, it replays deterministically with no model in the loop.

Read the design write-up View on GitHub Documentation
Banks run a long tail of back-office applications with no API. When an AI agent needs to get real work done, the only way in is to drive the UI the way a human operator would. Doing that with an LLM on every invocation is slow, expensive, non-deterministic, and unauditable — and the last three are disqualifying in a regulated environment.

Design commitments

Each is enforced by an invariant test that fails the build if it stops holding.

Deterministic Replay

Same artifact + same inputs + same app state = identical decision trace. No model in the loop, zero temperature, no network calls to LLMs.

Semantic Targeting

Controls are identified by role, accessible name, and structural anchors — never brittle CSS selectors. A six-rung ladder survives markup churn.

Policy Chokepoint

Every action — from LLM discovery, replay engine, or human operator — passes through one authorization chokepoint. Zero bypasses, zero exceptions.

Fail Closed

Unknown UI states stop the run immediately. Ambiguous targets are refused, never guessed. In banking, an unverified click is an incident.

Human Escalation Lease

An operator takes the live session, acts under policy, and hands it back. The engine re-anchors and resumes at the right step, not step 1.

Multi-Tenant Overlays

A rebranded tenant label requires a four-line overlay document, not a re-record. Drift is quantified per tenant before replays fail.

Run it yourself

One command walks the whole scenario end to end, on your machine.

# venv, dependencies, headless Chromium
$ make setup
# all 12 stages — falls back to a recorded transcript when no model is configured, and says so
$ make demo
# optional: a genuine LLM-driven discovery (needs an OpenAI-compatible endpoint in .env)
$ make discover

One path to the surface

Discovery, replay and a human operator all reach the browser the same way. Nothing dispatches without passing policy.

Action
click, type, navigate
→
TargetResolver
resolve or refuse
→
PolicyEngine
authorize
→
SurfaceDriver
dispatch
  • Replay never calls or imports the LLM
  • No action reaches a driver without policy authorization
  • Target identity is semantic, never a CSS selector
  • Human input cannot bypass policy or evidence
  • Unknown UI states fail closed
  • Every sink is redacted — logs, artifacts, LLM prompts
  • Business outcomes are not failures
  • Automation may only act while it holds the session lease
  • Capabilities are immutable and content-hashed
  • The domain layer is pure — no I/O, no network, no browser
